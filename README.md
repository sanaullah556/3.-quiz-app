# Quiz App

A small learning project: a general-knowledge quiz web app with multiple-choice questions and score tracking.

## What it does
- Fetches quiz questions from the public **Open Trivia Database** (opentdb.com) — REST + JSON
- Lets the player pick a category and answer multiple-choice questions
- Saves quiz results in a small database

## Tech used
- React + TypeScript (frontend)
- TypeScript server with a SQLite database (Drizzle ORM)
- Public REST API integration: https://opentdb.com/api.php
